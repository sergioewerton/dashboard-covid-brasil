# 📊 Dashboard COVID-19 Brasil

Análise de dados da pandemia de COVID-19 no Brasil utilizando Python, Pandas e Matplotlib.

## 🖼️ Visualizações geradas

- Top 15 estados com mais casos
- Top 15 estados com mais mortes
- Evolução total de casos no Brasil (2020–2023)

## 🛠️ Tecnologias utilizadas

- Python 3.13
- Pandas
- Matplotlib
- Seaborn
- Requests

## 📦 Como executar

1. Clone o repositório:
git clone https://github.com/sergioewerton/dashboard-covid-brasil.git

2. Instale as dependências:
pip install pandas matplotlib seaborn requests

3. Execute o script:
python app.py
